# MultiCuda API Excel

MultiCuda API Excel is an internal integration application used to support sales conducted through Allegro.

The application uses the Allegro REST API to:

- retrieve information about our own Allegro offers,
- retrieve orders and sales data,
- retrieve product catalogue, category and parameter data,
- prepare data for analysis in Microsoft Excel,
- prepare, create and manage Allegro offers.

The application is used exclusively for the company's internal business operations and is not provided as a service to third parties.
